# プライバシーポリシー修正案（お問い合わせの保存期間）　※案・未適用

対象: src/pages/privacy.astro の「お問い合わせでお預かりする情報」。
このサイトのプライバシーポリシーはサイト専用（アプリ側の文面は projects/morilab-legal にあり別管理）。共有元は無いので、この1か所だけを直せばよい。
文言と期間は本人が決める。下は案で、privacy.astro 本体は変更していない。

```diff
   <h2>お問い合わせでお預かりする情報</h2>
   <p>
-    メールでお問い合わせをいただいた場合、返信と内容の確認のためにメールアドレスと本文をお預かりします。
-    これらはお問い合わせへの対応にのみ使用し、ご本人の同意なく第三者へ提供することはありません。
-    対応が終わり、保管の必要がなくなった時点で削除します。
+    お問い合わせを受け付けるために、メールの内容と送信者のメールアドレスを取得します。
+    これらは返信と内容の確認のためだけに使い、ご本人の同意なく第三者へ提供することはありません。
+    保存期間は、対応が終わってから6か月（案）とし、過ぎたものは削除します。
   </p>
```

決めること: 期間（6か月は案）、「対応が終わってから」か「受信から」か、日付（最終更新日）の更新。
